# Installer self-sufficiency — v1.3.5 + v1.3.6

## What the setup.exe installs
- The Electron app itself (runtime, icon, everything) — always.
- **ffmpeg.exe + ffprobe.exe** (gyan.dev essentials) bundled inside the setup
  via `extraResources` → land in `resources/vendor/` (v1.3.5).
- **yt-dlp.exe** bundled as an offline fallback (v1.3.5), and — since v1.3.6 —
  **refreshed during installation**: the NSIS `customInstall` macro downloads
  the current yt-dlp release over the bundled copy, so YouTube downloads work
  with the newest yt-dlp on day one. Failure is non-fatal (bundled copy kept).

## Tool resolution order (downloader.cjs resolveTools / main.cjs findFfmpegPath)
1. `YOUR_PLAYER_TOOLS_DIR` env override
2. Bundled: `process.resourcesPath/vendor` (installed) or `<repo>/vendor` (dev)
3. PATH
4. Program Files fallbacks

## Build pipeline
- `npm run release` → `scripts/fetch-vendor.cjs` first (downloads yt-dlp.exe +
  ffmpeg zip into `vendor/`, skips already-present files, extracts via
  System32 tar with PowerShell fallback) → electron-builder → upload.
- `vendor/` is gitignored; the fetch script is committed.

## Verification performed
- v1.3.5: `resolveTools()` with PATH emptied resolves bundled tools; binaries
  run (`yt-dlp 2026.08.19`, `ffmpeg 9.0.2`); `resources/vendor/` present in
  win-unpacked; installer 89 → 160 MB; release assets verified.
- v1.3.6: standalone NSIS tests of the exact macro code — curl path (exit 0,
  17.8 MB, `--version` OK), forced PowerShell fallback (same, after fixing
  NSIS `$'` escaping → `\"` nesting), size gate accepts 17.8 MB / rejects
  failures; full simulated install (copy bundled yt-dlp → download fresh →
  size check → swap → run swapped binary: `2026.08.19`); rebuilt installer
  contains `resources/vendor/{ffmpeg,ffprobe,yt-dlp}.exe` (7z listing).
  INetC plugin was tested first and returned `U` on every URL — abandoned
  for nsExec+curl/PowerShell.

## Limitations
- The real installer was not run as an actual setup wizard on a clean machine;
  the customInstall logic was verified via an equivalent standalone NSIS
  script using the same NSIS runtime, plugins, and commands.
- The installed yt-dlp ages with each release; rebuild to refresh, or add an
  in-app updater later.
